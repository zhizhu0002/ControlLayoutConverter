ZL

FCL · ZL1 · ZL2 控件转换

三格式互转，离线处理，不上传文件
准备就绪：选择一个 ZL1 布局 JSON 文件

1导入 ZL1 布局

选择 JSON 文件，或在下方直接粘贴内容。

2转换为 ZL2 格式

支持 FCL、ZL1、ZL2 六种转换方向，尽量保留图层、抽屉、样式和按键事件。

3保存结果

迁移完成后，下载 JSON 或复制内容保存。

使用说明 & 原理
  1. 点击「选择文件」或粘贴 ZL1 布局 JSON。
  2. 点「开始迁移」，自动生成 ZL2 格式（info / layers / styles，editorVersion 10）。
  3. 点「下载」保存为 原名-ZL2.json，导入 ZalithLauncher 2 即可；若下载被浏览器拦截，用「复制结果文本」另存为 .json 文件。

换算依据：ZL1 尺寸存 Dp、位置为物理像素表达式（px()/margin/preferred_scale），ZL2 用 dp 尺寸 + 0~10000 位置百分比。密度在所有项中线性可约，故直接在 800×360 Dp 参考画布上求值，位置/圆角/颜色均精确等价。
